# Considerations
*what should you look out for when feeding grain?*
~
large amount of starch causes acidosis 
Low in calcium - add limestone

# Dietary composition
*How common is it? DM%? Energy/protein lelvels? Compare pulse crude protein to grain*
~
Most common feed type
90% DM
Varying energy/protein
Pulses have higher crude protein - use with grain to improve crude protein

# Adjusting to a grain diet considerations
*How long should it take and why?*
~
Starting on an entirely grain diet causes [[Lactic Acidocis]] if have low acid detergent fibre (wheat)
Gradual introduction over 3 weeks
Move using auger to a trough to minimise loss
