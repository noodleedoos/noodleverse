# Main classes
~
Flies, lice, ticks

# Common and Trends
~
Flies can be problem for all species – particularly animals producing fibre = fly-strike, but can be annoying and spread disease in all 
Tick and tick borne diseases historically mostly Northern Australia but also higher rainfall coastal areas
