# Key considerations
~
- Is the problem likely to be self-limiting
- Does the animal need treatment?
	- Symptomatic treatment 
	- Specific / invasive / aggressive treatment
- Does the animal need surgery?
		- Elective / emergency
- Does there need to be more investigation?
	- Individual / herd

# Refined problems list vs Priority differential Diagnosis List
~
- Refined: most important problems at the top
- Prioritised differential: most common diagnosis

# History collection
*What should you gather?*
~
- Description of Nature and timeframe of presenting complaint
- [[Prophylaxis]] 
- Current Medications
- Prior treatments
- Appetite
- Changes in body condition

# Dietary Information collection
~
- Current diet quality, quantity, provision
- Changes
- Access to other food sources and toxins

# Observation from a distance
*6 things you can observe*
~
- Demeanor/behaviour
- Posture/gait
- Defacation/urination
- Respiratory rate
- Envrionment (bedding, hygiene, ventilation)

# Physical Examination
*8 Common areas*

- [[Body and Fat Condition Score]]
