# Structure and Function
*What colour? What does it contain lots of and little of?*
~
Lots of sarcoplasm, few myofibrils
High [[myoglobin]] = dark red colour
Lots of mitochondria for cellular respiration
O - oxidative
N - numerous mitochondria, sarcoplasm which contains myoglobin (few myofibrils)
E - endurance activities
