# Function
~
Specialised junctions that connect cardiac muscle cells 
help make electrical and mechanical communication fast and allow heart to beat as coordinated unit

# Structure
~
- Adhering junctions - anchor actin to adjoining cells
- Desmosomes - cell-cell adhesion
- Gap junctions - direct communication
