# Description
*Structure, solubility, synthesis, storage, secretion, transport, receptor site, action*
~

# Structure
~
Small molecules from tyrosine groups (have NH2 group)

# Solubility
~
Hydrophillic

# Synthesis
~
Cytosol

# Storage
~
Secretory (Chromaffin) granules

# Secretion
~
Exocytosis

# Transport
~
Free hormone or bound to plasma proteins

# Receptor site
~
Surface of target cell

# Action
~
Second messenger system [[Gt Proteins]], [[Gi Proteins]], [[Gq Proteins]]


# Regulation
~
Adrenalin = stress
No negative feedback but action stopped by short half life of hormones - degrade quickly

# Function
~
1. Adrenal medulla of adrenal glands on top of kidneys produce adrenaline following sympathetic stimulation
2. Response: metabolic effects like increasing heartrate
