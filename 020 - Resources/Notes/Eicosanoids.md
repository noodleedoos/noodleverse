# Description
~
Relatively small (C20 compounds)

# Production
~
Produced on demand, not stored
1. Phospholipids via [[PLA2]] -> Arachidonic acid
	1. [[COX]] -> [[Prostanoids]]
	2. [[LOX]] -> [[Leukotrienes]]
![](https://i.imgur.com/YQ35I7O.png)

# Functions
~
[[pProstaglandins]] - vasodilators regulate blood flow
[[Thromboxanes]] - induce platelet aggregation/promote vasoconstriction
[[Leukotrienes]] - allergy, neutrophil chemo-attraction, vascular permeability
![](https://i.imgur.com/Q3f3BZc.png)

# Drug Effects on Eicosanoids
~
- Steroids inhibit [[PLA2]] 
- [[NSAIDs]] and [[Aspirin]] inhibit COX
![](https://i.imgur.com/QSIM6zC.png)
