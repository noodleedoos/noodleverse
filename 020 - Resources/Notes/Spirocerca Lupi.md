# Affected Species
~
Dogs, scavengers, wild canids

# Aetiology
~
Stomach -> aortic wall -> distal oesophagus -> granulomatous inflammation and fibroplasia -> neoplasia
Sequelae: dysphagia, perforation, neoplasia ([[Fibrosarcoma]])

# Charcaterisation
~
Nodules beneath mucosa of granulomatous inflammation macrophages where parasites are embedded
