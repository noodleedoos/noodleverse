# Description
*Why should we use breedplan*
~
For traits like growth, there are many genes involved
Expression = combination of genes and enviornment
Breenplan uses Best Linear Unbiased Predictor BLUP analysis to produce [[Estimated Breeding Values]]
Compares result to genetic base in particular year
Use actual animal data combined with all relative data and cohort data
Not full physical information to assess the animal
Allow faster genetic progress

# Breedplan EBV Measures
~
EBVs: Weight, fertility, carcase
Things to measure: Joining, birth, weaning, yearling, maturity
