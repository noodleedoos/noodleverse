# Types

# Description
*Solubility, production, secretion,  transport, life, function, storage, action*
~

# Solubility
~
Lipophillic

# Production
~
Produced in thyroid

# Secretion
~
Exocytosis

# Transport
~
Active transport across cell membranes bound to plasma proteins (thyroxin binding globulin)

# Life
Long half life

# Function
Regulate basal metabolic rate (slow)
- increased metabolic rate
- increased O2 consumption by mitochondria
- Nutrients
- Thermogenesis

# Storage
~
Thyroglobulin in colloid follicles, then cleaved to form prohormone [[Thyroxine]] and to a lesser extent [[Triiodothyronine]]

# Structure
~

# Functions
1. Increase metabolic rate + O2 consumption by mitochondria


# Regulation of T3 and T4 Secretion
~
[[Thyroid Stimulating Hormone|Thyrotropin]] from hypothalamus in response to blood levels of thyroid hormones
![](https://i.imgur.com/79rHh7c.png)


*Describe how regulation of the thyroid hormone is a negative feedback loop*
~
1. Thyroid hormon level drops below normal range and is detected
2. Thyrotropin releasing hormone (TRH) is released from hypothalamus
3. TRH causes TSH production from Anterior Pituitary gland, which downregulates TRH production
4. TSH causes thyroid to produce thyroxine, which downregulates the production of TSH and TRH
